# FocusFlow

> Turn scattered work into focused progress.

A premium, production-quality frontend homepage and interactive workspace built for the **Acdyon Technologies Frontend Challenge — Part 2: The Premium Home Page**.

## Features

* **Productivity Dashboard**: High-fidelity SaaS dashboard with local task states and progress metrics.
* **Task Management UI**: Interactive task filters (All, Pending, In Progress, Completed) and completion state toggling.
* **Interactive Focus Timer**: Polished 25:00 Pomodoro/Focus Session timer with countdown, pause, reset, and progress ring.
* **Responsive Design**: Custom-crafted breakpoints tested at 390px, 768px, 1024px, and 1440px with zero horizontal scroll.
* **Product Preview**: Realistic SaaS interface demonstration using structured local JavaScript models.
* **Responsive Navigation**: Desktop bar with smooth anchor links and functional mobile menu drawer.

## Tech Stack

* **React** (v18)
* **JavaScript** (ES module standard)
* **Vite** (v5)
* **Tailwind CSS** (v4)
* **Framer Motion** (v11)
* **Lucide React** (Icons)
